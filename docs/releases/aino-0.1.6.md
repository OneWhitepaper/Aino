# Aino 0.1.6

## 更新内容

- **Work / Code 双模式**：在同一个 Aino 中切换办公和编码工作区，共用账户与模型设置，并分别保留会话与草稿。
- **内置原生 Codex 编码引擎**：Code 支持项目理解、代码修改、命令执行、操作审批、停止任务和会话恢复，可查看执行进度与代码差异。
- **模型接入更顺畅**：改进协议自动检测、Responses / Chat Completions / Messages 适配，以及切换模型后的历史兼容处理。实际能力仍取决于所选模型与服务的接口支持，不会后台替换模型或扣费渠道。
- **跨模式任务交接**：支持在 Work 和 Code 之间交接需求摘要及选定文件，并保留关联会话入口。
- **桌面体验与稳定性改进**：优化文件预览、浏览器和工作面板，修复模型首次发送、图片选择、会话列表及 Windows 内嵌运行时等问题，同步上游运行时更新。
- **同账号本地历史恢复**：同步历史会话时保留 Work / Code 模式、模型和项目绑定，并迁移必要的原生 Code 线程及工作文件。同步后可继续原对话，重启后仍可接续；不同账号的历史保持隔离。

## 本次提供的版本

- **macOS Apple Silicon（arm64，M 系列芯片）**：DMG 安装包及软件内更新 ZIP。

本次仅发布 macOS Apple Silicon 版本，不提供 Windows、macOS Intel 或 Linux 的 0.1.6 安装包。历史版本文件保持不变。

## 安装与更新

**已有 Aino 的苹果芯片 Mac 用户**：先保存正在执行的工作，在 Aino 的「设置 → 关于」点击「立即检查」，发现 v0.1.6 后点击「立即更新」。软件下载并验证更新包后会自动退出、安装并重新打开，无需手动拖拽 DMG。若暂未出现提示，请完全退出并重新打开 Aino 后检查。

已验证 v0.1.4、v0.1.5 苹果芯片正式客户端的真实软件内升级、自动重启、升级后聊天与工具执行，以及用户状态、插件和原本地历史数据保留。升级不会自动把未归属账号的旧历史导入其他账号；需要时使用同账号历史恢复入口。

**首次安装或手动更新**：从 [Aino 官网下载页](https://petoi.cn/download.html) 获取 DMG。退出 Aino 后打开 DMG，将应用拖入「应用程序」并替换现有应用；不要删除用户数据。

**本次仅推送苹果芯片版本**。旧版 Intel 客户端共用更新地址，可能看到 v0.1.6 提示，但会拒绝下载、安装苹果芯片更新包；Intel 和 Windows 本次仍使用 v0.1.5，不要手动安装 arm64 包。

Mac 安装包已使用 Developer ID 签名并完成 Apple 公证。请核对官网下载来源和 SHA-256 校验值。

安装包文件名、大小和校验值以本发行版的 `release-files.json` 与 `SHA256SUMS` 为准。

源码提交以本发行版 `release-files.json` 中记录的完整提交号为准。
