# Aino 0.1.6

## 更新内容

- **Work / Code 双模式**：在同一个 Aino 中切换办公和编码工作区，共用账户与模型设置，并分别保留会话与草稿。
- **内置原生 Codex 编码引擎**：Code 支持项目理解、代码修改、命令执行、操作审批、停止任务和会话恢复，可查看执行进度与代码差异。
- **模型接入更顺畅**：改进协议自动检测、Responses / Chat Completions / Messages 适配，以及切换模型后的历史兼容处理。实际能力仍取决于所选模型与服务的接口支持，不会后台替换模型或扣费渠道。
- **跨模式任务交接**：支持在 Work 和 Code 之间交接需求摘要及选定文件，并保留关联会话入口。
- **桌面体验与稳定性改进**：优化文件预览、浏览器和工作面板，修复模型首次发送、图片选择、会话列表及 Windows 内嵌运行时等问题，同步上游运行时更新。

## 本次提供的版本

- **macOS Apple Silicon（arm64，M 系列芯片）**。
- **Windows x64**：ZIP 便携版，完整解压后启动。

本次不提供 macOS Intel、Windows ARM64 或 Linux 的 0.1.6 安装包。历史版本文件保持不变。

## 安装与更新

从 [Aino 官网下载页](https://petoi.cn/download.html) 获取对应版本。更新前退出 Aino，并保留现有用户数据；Windows 便携版不要直接在压缩包内运行。

安装包文件名、大小和校验值以本发行版的 `release-files.json` 与 `SHA256SUMS` 为准。
