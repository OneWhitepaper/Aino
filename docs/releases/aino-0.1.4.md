# Aino 0.1.4 更新说明（候选稿）

本次更新统一桌面界面，并完善会话、模型配置与文件工作台的使用体验。

- 统一首页、侧边栏、设置、技能、消息平台、Agent Hub 与提示窗口的字体、间距和交互风格。
- 文件、浏览器、终端与审查集中在工作面板的标签页中，保留文件编辑、保存、预览及分屏操作；摘要始终跟随会话。
- 完善任务暂停与继续，修复普通会话与 Agent Hub 的切换和页面状态问题。
- 修复后端重启时与后台请求竞争导致的启动失败，共享同一后端的会话会重新连接到替换后的服务。
- 简化默认模型、官方服务商和自定义 API 配置，支持删除自定义 API 连接及其独占凭据，并保留其他连接仍在使用的凭据。
- 对话中的模型选择只影响当前会话，新建会话恢复设置中的默认模型；推理强度保留原有档位方式。
- 接入 Aino 内置生图与改图，图片模型和文字模型分开管理，出图质量默认使用“自动”。
- 重整账户、充值及设置分类，补充中文说明，改善外观设置、上下文统计和快捷操作。

此文件用于发行准备。最终版本的验证记录、安装包哈希与签名状态随候选包另行记录；不代表已经发布更新。
