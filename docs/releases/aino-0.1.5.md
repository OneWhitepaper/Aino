# Aino 0.1.5

## Highlights

- **Bot 与群聊协作更顺畅**：优化机器人导航、名称与头像，实时展示思考、工具执行和协作进度。
- **子智能体会话可直接查看**：点击协作胶囊中的任务，在右侧面板查看对应子智能体的实时记录，保留当前会话与草稿。
- **工作面板体验更统一**：文件、浏览器、终端与审查沿用标签页操作，改善摘要位置、分割线和展开过渡。
- **账户与模型使用更稳定**：完善账号数据隔离、默认模型继承、可用模型切换与设备授权信息。
- **运行服务与扩展能力更新**：同步上游 v0.23.1，改进插件、上下文和任务恢复；停用云端会话同步，本地会话继续保存。

## 安装与更新

从 [Aino 官网](https://petoi.cn/download.html) 获取与电脑系统、芯片架构相符的安装包。更新时保留现有用户数据目录。

具体可用平台、安装包格式及校验值以官网实际下载列表为准。
