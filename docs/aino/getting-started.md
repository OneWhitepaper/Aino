# 快速开始

[返回帮助首页](README.md)

## 开始一次任务

1. 打开 Aino，登录自己的账户。账号切换会进入各自的本地工作区。
2. 打开“设置 → 模型”，确认当前默认主模型可用。使用内置模型时，账户需要具备该模型的使用权限。
3. 新建普通会话，或从 Bot 列表打开需要的机器人。
4. 在输入框说明目标；需要处理本地资料时，选择项目或添加文件。
5. 发送后查看思考、工具执行和回复状态；遇到审批卡片时，核对实际操作再决定是否允许。

无需先配置全部工具。只有任务需要某个第三方服务、MCP 或消息平台时，再添加相应授权。

## 模型怎么选

“设置 → 模型”中保存的默认模型用于之后创建的会话。聊天输入框旁的模型选择用于当前会话，不会因为一次临时切换就把全部 Bot 的默认配置改掉。

新 Bot 会继承其所属配置中已保存的默认模型。确实没有可用默认配置时，需要选择一个可用模型，不应凭服务商名称自动使用尚未配置的 API。

内置文本模型与生图模型分开配置。上传图片不代表任意模型都能改图；编辑图片还需要对应的图片编辑能力。参见[模型与生图](models-and-images.md)。

## 项目、工作区和文件

选择项目或文件夹后，先确认当前路径符合任务范围。机器人可在已授权范围内读取文件、执行命令和生成产物；它的回复不等于操作已成功，必要时查看工具结果或实际文件。

从会话打开的文件、网页、审查和终端通过面板查看。摘要属于会话区域，不与文件标签页混排。参见[文件与面板](files-and-panels.md)。

## 任务运行时

- 普通状态显示当前正在进行的思考或操作，不是固定的“正在回复”。
- 委派子智能体后，顶部出现协作胶囊；点开可看任务来自哪个会话、哪个助手正在执行。
- 停止操作不会撤销已经写入的文件、发出的请求或其他外部影响。恢复任务前先核对已完成的部分。
- 连接中断时保留草稿，按页面提供的恢复入口处理。没有确认送达的消息不要反复作为新消息发送。

## 退出、重新登录与本地保存

同一账户在同一安装中重新登录，会回到自己的本地工作区；另一个账户有独立的会话、配置及应用浏览器分区。云端会话同步已经下线，换电脑不会自动带回旧电脑的聊天记录。

电脑中的普通项目文件仍由操作系统管理。应用内账户隔离不会替你删除共享文件，也不等同于给本地文件加密。参见[账户与设备](accounts-and-devices.md)。
