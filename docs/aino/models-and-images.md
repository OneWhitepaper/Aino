## 三种模型来源

| 来源 | 需要配置什么 | 权限和费用 |
| --- | --- | --- |
| Aino 内置模型 | 登录账户，选择账户可用的模型 | 由 Aino 服务逐次核验权限与结算 |
| 第三方服务商 | 选择现有服务商，填入其 API Key；按服务能力获取模型 | 对应服务商负责 |
| 自定义模型 | 兼容接口地址、API Key、模型 ID 或可获取的模型列表 | 你配置的 API 服务负责 |

DeepSeek 等官方服务商与 Aino 内置的同系列模型是不同的接入来源。模型名称相同，也不能混用凭据。未配置的服务商不应被当作聊天中已可用的模型。

## 保存默认主模型

在“设置 → 模型”选择默认主模型并保存。此项决定后续会话使用的默认模型；新建 Bot 在对应配置中继承已保存的默认设置。

聊天输入框旁的模型选择器用于当前会话。切换后不会自动改写其他会话或机器人的默认模型。需要恢复模型时，选择结果先暂存，点击“应用到当前会话”后才提交；恢复流程不会自动发送原提示。

设置页面还提供回退、辅助模型、委派模型及多模型协作等配置。它们分别服务于特定功能，不必为了开始普通聊天全部配置。某个辅助模型不可用时，先核对受影响的能力，不要直接重置全部主模型配置。

## 第三方与自定义 API

已有官方服务商优先在第三方服务入口配置。需要使用中转服务、自己部署的兼容接口或独立模型 ID 时，使用自定义模型入口。

保存前核对：接口协议、完整基础地址、密钥及模型 ID。接口返回的显示名称不一定等于请求使用的模型 ID。只有服务支持相应模型目录时才能自动获取列表；获取失败并不能证明没有任何模型可用。

已保存的自定义配置可以从其配置入口完整删除。删除前确认没有正在执行的会话依赖该配置；它不会撤销第三方平台上的原密钥，也不会取消第三方订阅。

不要在普通消息中发送 Key，使用配置表单的密钥字段。诊断日志和截图也应隐藏密钥。

## 文本推理强度

推理强度控制文本模型相关的思考参数，沿用当前模型选择器提供的设置。不同模型和接口对参数的解释可能不同；Aino 没有承诺全部模型支持同样档位，也不能把显示的档位视为官方能力认证。

不要把出图质量当成文本推理强度，也不要把上下文统计当成最终账单。

## 生图和改图

“设置 → 模型”的图片生成区域单独管理生图工具和模型。它与文本主模型是两条配置；图片服务不可用不应让正常文本对话一起失效。

1. 选择账户可用的生图模型并保存相关配置。
2. 发出清楚的图片创作要求，说明主体、风格、尺寸或用途。
3. 改图时提供需要编辑的参考图片，说明要保留和修改的内容。
4. 查看工具执行结果和生成文件，确认实际完成。

出图质量默认“自动”，用于质量/精细度选择。文生图与图片编辑是否可用，由实际服务及模型决定；只支持文生图的接口不能仅靠一句提示升级为图片编辑。

上传图片也可能用于文本模型识图，与调用生图工具编辑图片不同。需要编辑时应确认所选图片模型及接口支持参考图输入。

## 模型不可用时

先区分账户权限、余额、设备授权、第三方凭据和服务连接。通过当前会话恢复入口更换可用模型后再继续任务，不要为切换模型新建设备 Key。参见[账户与设备](accounts-and-devices.md)和[故障恢复](troubleshooting.md)。
