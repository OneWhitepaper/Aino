# 设置

[返回帮助首页](README.md)

## 先看当前作用范围

设置可能属于当前账户工作区、所选 Bot/配置、当前连接或本机桌面。修改前先确认正在配置谁；不同范围不会因为界面在同一个窗口里就自动合并。

外观、设备设置和某个 Bot 的工具配置不一定具有相同范围。云端会话同步已下线，也没有“所有设置自动同步到每台设备”的承诺。

## 各页面负责什么

| 页面 | 常用内容 | 使用提醒 |
| --- | --- | --- |
| 我的账户 | 账户资料、套餐/余额、设备授权 | 设备授权与 Bot 配置分开管理 |
| 模型 | 默认主模型、图片生成、回退、辅助及委派模型 | 聊天中临时切换不改写所有默认值 |
| 外观 | 主题、字体及显示偏好 | 嵌入内容也应跟随当前主题 |
| 对话 | 行为、个性、时区、思考显示与输入相关设置 | 系统提示相关修改通常在新会话生效 |
| 工作区 | 项目路径、仓库发现、Shell、环境与文件执行 | 核对实际工作目录及当前连接 |
| 安全 | 命令审批、隐私、安全与检查点 | 放行命令不意味着撤销其副作用 |
| 浏览器 | 浏览器配置与私有网络访问 | 网页账户属于相应账户/浏览器范围 |
| 记忆与上下文 | 长期记忆、上下文与压缩 | 压缩与账单统计是不同概念 |
| 语音 | 语音对话、转写、朗读 | 依赖所选服务、权限及设备 |
| 高级 | 运行轮数/重试、工具、密钥、终端、输出等 | 仅在确有需求时调整运行限制 |
| 通知 | 桌面及应用内提醒偏好 | 系统权限也可能影响原生通知 |
| 网关 | 后台运行及消息平台连接 | 不代表提供 Aino 云端托管 |
| 插件 | 已安装扩展与启用状态 | 安装、启用和第三方授权是不同步骤 |
| 快捷键 | 当前操作与按键绑定 | 以本机显示的绑定为准 |
| 关于 | 应用版本与更新入口 | 查看版本不代表服务器也已更新 |

具体选项只会在相应组件、连接和权限支持时显示。不要根据上游文档中的页面名称寻找 Aino 中不存在的旧入口。

## 工具与密钥

工具配置与密钥放在高级设置的相应区域，可以分别展开。只有启用所需工具并满足其凭据/环境要求后，机器人才能调用；工具数量多不代表每个都已经授权可用。

秘密值使用密钥输入或受支持的凭据存储入口，不写进普通描述、聊天消息或项目规则。命令行配置中的行为选项进入 `config.yaml`；`.env` 用于秘密值。

## 记忆和个性

长期记忆用于在后续会话保留偏好与有用信息；聊天历史、压缩摘要和系统提示是不同的存储层。修改个性或技能后，已有会话通常继续使用自己的缓存提示，保护上下文连续性和缓存成本。

需要使旧会话采用当前提示来源时，使用[受控刷新](prompt-refresh.md)，而不是手工批量替换历史消息或删除数据库。

## 命令行核对配置

已有 CLI 的技术命令仍叫 `hermes`。在确认它指向同一账户工作区和正确配置后，可用下列只读命令核对：

```text
hermes config path
hermes config get model
hermes config check
```

`config get` 默认隐藏秘密值。确实需要修改时使用当前 CLI 帮助支持的 `config set`、`config unset` 或 `config edit`；不要把桌面数据目录猜成固定的 `~/.hermes`。

使用桌面连接远程运行服务时，远程配置和本机桌面偏好仍是不同的范围。排错先核对范围，再决定是否修改。

## 使用本机浏览器登录状态

支持此能力的本地连接可在浏览器设置中明确启用“使用真实浏览器登录状态”，并重新导入已有登录。远程、SSH 或 Cloud 连接不能导入这台电脑的浏览器凭据。导入的是网页登录状态，与 Aino 账户登录分开管理。

关闭后会清理该功能导入且仍归其管理的 Cookie，不代表注销后来手动登录的所有网站。共享电脑上启用前请确认当前 Aino 账户和浏览器来源。运行条件与隐私边界见[技术补充](handbook/references/runtime-0231-additions.md)。
