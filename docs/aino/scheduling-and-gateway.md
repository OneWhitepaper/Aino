# 调度与网关

[返回帮助首页](README.md)

## 网关是什么

网关是让 Aino 运行服务连接外部消息平台、接收消息并维护后台执行的进程。它可以运行在自己的电脑或自己管理的服务器上；“网关已连接”不表示 Aino 已替你提供云端电脑。

普通桌面会话、外部消息平台、群聊和定时任务可以共用同一智能体核心，但各自保留来源、配置与授权边界。某个平台连通不代表其他平台已经登录。

## 连接消息平台

从对应设置或配置入口添加平台凭据，按服务方要求完成机器人、Webhook 或授权步骤。不同平台需要不同前提，不能用一个平台的密钥代替另一个。

先做最小验收：从目标平台向机器人发送一条测试消息，确认在正确会话中收到回复；再测试附件、通知或群功能。消息回错会话时，不要继续发送敏感内容，应先核对连接、账户和会话归属。

关闭桌面窗口后能否接收外部消息，取决于网关是否仍运行。电脑休眠、断网、凭据到期和进程退出都可能影响任务，不能保证单靠窗口最小化就持续工作。

## 定时任务

支持定时任务的当前会话可在用户明确要求时创建计划。创建时确认：

- 要执行的目标和使用的配置/机器人；
- 时间、周期和时区；
- 工作目录及文件访问范围；
- 结果要回到哪个会话或消息平台；
- 是否会产生外发、写入或付费调用。

先查看保存的计划与下次运行信息，再确认已创建成功。计划存在不代表运行已经完成；检查最近运行记录和实际结果。

已有 CLI 的只读核对入口包括：

```text
hermes cron --help
hermes cron list
hermes cron status
hermes gateway --help
hermes gateway status
```

这些命令必须指向实际持有任务的账户工作区/配置。用另一个独立 CLI 查看不到任务，不代表桌面的任务丢失。

## 子智能体与持久任务

协作胶囊展示当前会话委派的临时子智能体。它们通常依赖父任务的运行进程；关闭运行服务不会自动把它们迁移到后台服务器。

定时计划保存后可由运行中的调度器触发，仍需要进程、网络、模型及外部权限满足要求。对必须长期运行的任务，应使用受支持的网关/调度方式并管理主机运行状态。

## 托管服务与自行配置

部分连接器可能通过 Nous 或其他服务方提供托管能力。这类服务有独立账户、额度、可用性和费用条件；Aino 的平台账户不自动等于这些服务的账户。

自行配置的 MCP、API 和本地工具不必经过同一家托管商，但需要为每项能力准备真实替代服务、授权和依赖。不要仅删除托管配置就宣称能力已等价保留。

Aino 当前不提供会话云同步，也不因配置网关获得云端聊天备份。服务异常按[故障恢复](troubleshooting.md)处理。

## 保存的网关连接

支持共享连接表的版本会让桌面与 Webapp 读取同一份已保存连接，并按提示迁入旧记录。删除连接会移除该保存入口，不会删除远端会话或替你停止远端任务。

默认关闭凭据加密时，共享连接文件按操作系统用户权限保护，凭据以明文保存，供本机桌面与 Webapp 使用。显式开启桌面密钥加密后，凭据继续由系统钥匙串保护，不会因共享连接表而自动转为明文；Webapp 可查看和整理连接，使用或更新密钥时需要回到桌面解锁或明确关闭加密。不要分享连接文件，账户隔离与本机文件权限仍须保留。这份连接表不是会话云同步，也不会上传聊天历史。
