# 文件与面板

[返回帮助首页](README.md)

## 面板里的标签页

文件、网页、产物、终端与审查通过工作区面板查看。打开新的内容时使用相应标签页，不额外保留一列旧式文件页面。

面板跟随当前会话管理内容；明确固定的标签页可以保留。关闭标签页只关闭查看入口，不会删除磁盘文件。临时查看、保留或固定等操作以标签页当前提供的菜单为准。

在编辑器中改动文件后，注意保存状态。机器人回复“已修改”需要与实际文件或差异视图相互核对；审查展示修改内容，不代表改动已提交或部署。

## 预览与原文件

文本、图片、PDF 和 HTML 等内容按其类型使用对应预览。HTML 可以有源码查看与页面预览，两者针对同一个文件但承担不同用途。

远程连接中的路径属于运行服务所在的机器，不能拿本机同名路径替代。文件访问失败时先核对来源连接、权限和文件是否仍存在，避免误操作其他项目文件。

预览里的网页不能在未授权情况下静默打开外部系统页面。需要外部浏览器、登录或下载时，按实际界面进行明确操作。

## 摘要与上下文

摘要附着于会话区域，不加入文件标签页的最右侧。它是非模态查看：打开摘要后仍可编辑会话草稿；离开会话进入管理页面时隐藏摘要，不把另一条会话的内容显示过来。

上下文统计用于理解当前会话占用，可能包含估算或尚未完整统计的分类。它不等同于服务端计费用量；历史累计 token、当前上下文和本次计费用量应分别理解。

长会话可使用当前界面提供的压缩入口。压缩保留摘要而非完整逐字上下文，重要要求和未确认的信息应在继续前核对。普通界面更新不会自动改写旧会话缓存的系统提示，参见[旧会话提示刷新](prompt-refresh.md)。

## 在回复中交付文件

下面的媒体与挂件协议适用于具有桌面渲染能力的普通会话和 Bot 单聊。群聊使用自己的附件与消息流程；子智能体将结果返回主任务，由主任务按当前会话能力交付，不会因此获得直接操作桌面的权限。

机器人应先创建真实文件，再以文件/媒体入口交付。底层桌面媒体协议使用单独一行的 `MEDIA:/absolute/path`；它是产物协议，不是要求用户手动输入路径。

正文 Markdown 用于排版文字、表格、代码等。把内容写进一个 Markdown 代码块不会自动创建 `.md` 文件；需要文件时应明确要求“保存为 Markdown 文件并提供打开入口”。

## 内嵌交互组件

机器人可创建真实 HTML 文件，再用独立一行的 `::preview{file="path.html"}` 在会话中预览。嵌入内容应适配桌面的浅色/深色主题、内容宽度和键盘访问。

桌面为嵌入页面提供 `--foreground`、`--muted-foreground`、`--accent`、`--border`、`--card` 等主题变量和应用字体。制作内嵌小组件时沿用这些变量、透明背景和内容尺寸；独立完整网页可以自行设计版面。

已有交互桥保留 `data-hermes-send` 和 `window.hermes.send(...)` 技术名称。只有桥实际可用时才能发送后续交互；不要把它们改写成未经实现的新 API。点击更新后的结果应回到原会话/原组件，不能混入别的账户或连接。

## 终端打不开时

先确认当前会话的连接、工作目录与运行服务可用，再从面板重新打开终端。不要用新建会话来掩盖连接故障，也不要把另一账户或另一连接的终端复用到当前会话。参见[故障恢复](troubleshooting.md)。

## 在应用内浏览器填充登录

连接和当前页面支持时，浏览器标签页的钥匙入口可从凭据库填充已保存的登录。填充只针对明确选择的当前页面，不会自动提交表单。导航、换页或取消后，旧请求会失效；失败时重新确认页面再操作，不会静默改用另一个浏览器。自动化浏览器与应用内预览是不同目标。

## 让 AI 操作当前网页

告诉机器人在 Aino 内置浏览器中完成任务，面板会实时显示观察、操作、等待确认和用户接管状态。普通按钮和输入框优先使用页面提供的元素名称；开放的 Shadow DOM 与同源 iframe 使用同一条链路。需要看图操作时，模型必须支持图像输入，并先获取当前标签页截图。跨源 iframe 和封闭 Shadow DOM 的内容不能冒充已完成语义检查。

工具使用既有 `drive_preview`，不增加新的核心工具：

- `tabs` 列出当前会话的网页标签页和当前配置空间的固定页；`select_tab` 按返回的 `tab_id` 选择。切换保留原网页、未提交表单与滚动状态，弹出窗口的网页会在原窗口中显示。其他会话的私有页与其他配置空间的固定页不在列表中。
- `elements` 获取可操作元素引用；`click`、`double_click`、`hover`、`type`、`press` 使用这些引用。双击会发送两次正确的原生点击，按键支持 `Meta+A`、`Ctrl+Shift+ArrowLeft` 等组合；普通文本中的 `+` 和表情仍按文本输入。
- `screenshot` 返回当前网页图像、`tab_id` 和 `observation_id`。坐标操作必须使用这一张截图的标识；切换标签页、导航或页面变化后重新观察，不能沿用旧坐标。
- `dialog_status` 查看当前原生网页提示，`dialog_respond` 按准确的 `dialog_id` 接受或取消；这不是绕过用户授权的入口。敏感输入应由用户接管后填写。
- `upload_files` 针对已选文件输入框或与它关联的上传标签，选择用户确认的桌面本机绝对路径。网站“添加附件”按钮唤起文件选择时，先用 `dialog_status` 获取待处理的 `file_chooser.id`，再把它作为 `chooser_id` 传给 `upload_files`，无需猜测隐藏输入框的选择器。它不把远程服务中的同名路径当作本机文件。
- `downloads_status` 查看下载状态；附带 `download_path` 时，请求用户授权下一次下载保存到指定且尚不存在的本机路径。授权只对应一次下载，不授予批量下载或覆盖文件权限。`download_cancel` 按准确的 `download_id` 取消下载。

检测到提交、删除、付款、安全设置等后果较大的动作，以及截图坐标操作时，会要求用户核对网站和目标后确认。用户点击“接管”会取消当前操作，并让该标签页持续归用户控制；只有“交回 AI”后才能继续。切换窗口、导航或页面变动会使过时的观察与确认失效，动作完成后验收失败也不应直接重复提交。

能力由新会话建立时的工具定义提供。更新后需要使用新会话验收；不会为每一轮对话重建工具集或改写旧提示缓存。

支持 `session-transcript-v1` 的运行服务可以只读查看已存会话和受授权子任务的执行记录；查看不会恢复任务、发送新消息或创建收费推理。子任务已结束仍可能有历史记录，能查看不代表仍能继续或中断。压缩摘要、截断标记与普通消息分别展示，按[技术补充](handbook/references/runtime-0231-additions.md)理解读取边界。
