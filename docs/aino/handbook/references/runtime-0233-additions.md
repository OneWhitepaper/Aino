# Aino 技术参考 · 新版运行时与桌面兼容能力

[返回完整手册](../README.md)

本章对应 Hermes v0.23.3 及上游快照 `352b249f67` 的新增能力。
上游引擎版本与 Aino 安装包版本独立；能力是否可用仍以当前安装版本、
所连接网关通告、所选模型及用户授权为准。Aino 保留现有页面和组件。

## 长对话缓存与压缩

运行时按模型接口、实际用量及已知价格判断缓存策略。长工具执行期间的
缓存保温可能产生辅助请求，并非免费请求，也不保证所有中转服务都支持。
辅助调用仍受当前账户、会话、模型来源和费用规则约束，不应为保温而偷偷
更换模型、密钥或扣费渠道。

压缩先生成摘要，再将被移出上下文的工具结果归档；支持的执行环境会给
后续工具提供可读取的归档路径。归档不等于把原始工具结果继续放在每次
模型请求中，也不等于云端会话同步。

## 会话存储与更新后的历史恢复

上游将会话存储收口到 `persistence/` 和 `persistence_assembly.py`。
SQLite 仍是实际存储后端；这不是要求用户迁移到新的云服务。插件开发者
应使用公开的持久化接口，不依赖已退役的 `hermes_state_*.py` 内部模块。

Aino 历史会话仍属于对应账户；Work/Code 模式、所选模型、项目目录、
Code 线程和必要工作文件都参与可继续执行的恢复。不要把“列表能看到”
当成恢复成功；需要验证继续发送及重启后再次发送。

## 权限卡片

沙箱可以通过现有审批区域申请文件夹或网站权限。确认前先检查申请对象、
只读/读写范围及风险说明；拒绝和超时不代表已授权。普通输入框的回车不
应该替代对权限卡片的明确选择。是否持久化授权遵循对应卡片和后端的策略。

## 多助手等待与切换恢复

Bot 会话可以显示尚未完成的队友投递，让用户区分“正在等其他助手”和
“当前任务已经失败”。打开队友会话或关闭提示不应发送输入框中的草稿。

切换 Bot/工作配置时会显示实际加载、重连和失败重试状态。草稿及发送目标
属于原会话；切换尚未完成不能把消息发送到另一个账户、配置或模型路由。
Work/Code 的切换也不代表把既有对话交给另一套引擎重跑。

## 插件管理的本机后端

桌面 SDK 的 `host.setProfileBackend` / `host.clearProfileBackend` 可在用户
确认后，将指定配置交给本机插件后端，或切回原后端。地址仅限本机回环，
并非允许任意远程地址。启动、停止或重启期间的队列处理遵循现有提交身份
与恢复规则，不能重放结果不确定的有副作用请求。

这是一条插件扩展边界，不代表 Hermes 与 Codex 已变为同一个执行引擎，
也不会自动让所有 Work 工具在 Code 中可用。

## 客户端身份与活跃状态

连接可以向网关说明自己的客户端类型及会话活跃状态，供当前会话和插件
判断工作来自哪里。系统通知还需主进程确认实际可用性。这些会话运行信息
与用户可选择的共享指标上报是不同能力；不能据此默认为用户打开外发遥测。
