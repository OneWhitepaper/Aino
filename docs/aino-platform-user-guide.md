# Aino 平台账户、模型与钱包使用指南

本文描述本地开发版本的使用方式，不代表正式站点已开通全部功能。最新完成/未验证状态见 [实施进度](implementation/aino-platform-progress.md)。正式短信、模型和支付能力取决于服务端配置；开发验证码不能用于正式站点。

## 登录与已有账户

首次进入使用独立的小登录窗口。输入中国大陆手机号，阅读当前协议并完成需要的人机验证后获取短信验证码；验证码长度、有效期、重发等待时间以页面实际返回为准。服务端接受短信不等于手机已经收到，结果不明确时请等待冷却结束，不要连续发送。

如果已经在 Aino 模型站点有余额，先登录原账户并绑定手机号：邮箱账户可用原邮箱密码和验证器登录，第三方账户先在网站登录并绑定。绑定后仍使用同一个账户和余额，不能把被另一账户占用的手机号强行合并过来。没有开通的微信入口不会生成假登录二维码。

登录成功后恢复原桌面工作区。切换项目、工作区或 Agent 连接不等于切换商业账户，也不转移余额。设置 → 我的账户查看账户 ID、脱敏手机号/邮箱、昵称和退出入口；左下角用户名来自同一份账户信息。

记住登录依赖操作系统安全存储。不可用时只在本次运行中保持登录，不会改为明文保存。断网和登录失效不同：短时断网可重试，不必反复删除配置。

## 内置模型与自定义模型

- **Aino 内置模型**：平台根据当前账户权限提供目录。有余额或适用订阅额度时不需要手填 API Key；并不表示所有新用户都有赠送额度。
- **自定义模型**：继续使用自己配置的服务商、地址和 Key，费用由该服务商处理，不从 Aino 钱包暗中扣费。

设置 → 模型和聊天输入框均可选择模型。显示名、价格、上下文与能力来自服务端，不可用项会说明原因。已有明确的自定义默认配置保留，不因登录自动改为平台消费。没有可用内置模型时，应检查权限/额度或使用自定义模型，不能靠反复发送解决。

平台模型先创建待授权草稿，再完成主进程与 Agent 的受保护绑定，最后发送。授权失败时先恢复授权或重选模型，不应默认把同一任务完整重放。切换模型和取消流式回复可能仍有已产生的模型用量，最终费用以账本为准。

远程连接必须具备受保护连接及明确的平台额度授权。没有授权的远程后端仍可用原自定义模型，不会自动收到平台 Key。短时桌面授权不能当作关闭桌面后永久运行的定时任务授权。

## 钱包、消费与币种

在设置 → 我的账户中查看：

- 可用余额与冻结金额，单位为 **USD**；订阅额度/到期时间单独列出，不并入现金余额。
- 消费记录与充值订单；所有记录属于当前登录账户。
- 设备授权列表；撤销需要确认，可能要求验证器验证码或重新登录。

回复下的 Aino 费用来自真实用量记录。工具、标题、压缩等可能分别产生调用；未齐全时显示核对中或部分结算，不能把暂时没有记录理解成免费。原 token、耗时和上下文指标仍保留。

## 充值与恢复

点击充值，输入金额、选择服务端启用的支付宝/微信渠道，先查看报价。报价分别列支付金额、手续费和到账额度：例如支付币种为 CNY 时，到账仍以 USD 钱包单位显示；不能把两个数字直接等同。

确认创建订单后扫码，或通过可用的付款按钮在系统浏览器支付。二维码关闭只隐藏窗口，**不会取消订单**。重新打开将恢复原订单；取消必须点击单独的取消操作。

“已支付，正在到账”不代表账本已经入账。只有订单完成并读回钱包后才显示充值成功。网页跳回、截图或本地按钮不能替代服务端付款确认。

遇到网络超时、结果待确认或付款码过期，先刷新/恢复原订单，或到充值订单中查询，避免重复付款。服务端价格变化需要重新确认。金额被明确拒绝时可调整并重新报价；如果提示请求冲突，请从订单记录核对原订单，不要清除缓存来强行重建。

支付关闭或渠道未配置时，仍可以看余额和已有记录。不要把当前没有可用充值渠道当作余额丢失。

## 退出与安全边界

退出会清除本机平台登录材料和托管授权；活跃平台任务可能被中断。断网退出可能无法立即确认服务端撤销，必须留意页面提示。撤销当前设备授权后也可能需要重新登录。

项目文件、自定义模型配置和本机历史不会因平台退出而删除。本系统没有在这次接入中提供聊天云同步或操作系统级共享电脑隔离；旧账户的本机历史仍可能可读，不能把它误认为新账户可接管的付费会话。

## 测试说明

隔离测试使用临时 Electron userData、临时 HERMES_HOME 和本地假短信/模型/支付出口，不读取个人 Key，也不产生真实付款。界面和隔离测试通过与真实运营商送达、正式模型扣费、真实支付宝/微信到账是不同验收层级。
