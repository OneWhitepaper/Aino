# Source and adaptation

Upstream: https://github.com/Leonxlnx/taste-skill
Author: Leonxlnx. License: MIT, copyright 2026 Leonxlnx.
Public source and local tasteskill 2.5.1 were checked on 2026-11-16.

This is an Aino-native adaptation of the design practice, not the official
runtime kit. Asset dealers, headless-browser scripts, host hooks, stop gates,
shader/photo/icon collections and embedded third-party assets are not bundled.
The workflow is adapted for existing applications and preserves the user's
approved palette and layout rather than enforcing marketing-only defaults.
